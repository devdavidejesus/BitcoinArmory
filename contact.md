There is no official Armory email address. The best ways to reach the developers are:

 - **Bug reports and feature requests:** open an issue on the [GitHub issue tracker](https://github.com/goatpig/BitcoinArmory/issues). Include your Armory version, operating system, the Armory log file and steps to reproduce the problem. If relevant, attach Bitcoin Core's `debug.log` as well.
 - **Questions and support:** the [Armory board on Bitcointalk.org](https://bitcointalk.org/index.php?board=97.0).

## Reporting a security vulnerability

Please **do not** open a public issue for security problems. Report them privately through [GitHub's private vulnerability reporting](https://github.com/goatpig/BitcoinArmory/security/advisories/new) so the issue can be fixed before it is disclosed. If that form is not available, contact the maintainer privately on Bitcointalk.

## Beware of impersonators

The only official Armory website is **btcarmory.com**, and the source code and binaries are published only at [github.com/goatpig/BitcoinArmory](https://github.com/goatpig/BitcoinArmory). Armory is a desktop application and has **no mobile app**: any phone app using the Armory name, and any other website offering Armory downloads, is not made by the Armory developers.

The Armory developers will never ask for your wallet files, passphrase, paper backup or private keys, and will never offer to "recover" funds for a fee. Only download Armory from the [Releases](/releases/) page or the [GitHub releases page](https://github.com/goatpig/BitcoinArmory/releases), and always [verify the binaries](/docs/verify) before running them.
