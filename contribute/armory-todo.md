Done in the new C++ wallet format of the upcoming 0.97 release:

 - The wallet format can hold BIP 32 seeds (along with BIP 39, 44, 49 and 84)
 - Compressed key support

Still open:

 - Creating BIP 32 wallets and restoring from BIP 39 words in the interface
 - Hardware wallet support
 - BIP 9 deployment checking

Work on Armory is tracked on GitHub:

 - [Issue tracker](https://github.com/goatpig/BitcoinArmory/issues) - bugs and feature requests
 - [Project board](https://github.com/users/goatpig/projects/1/views/1) - what is being worked on for the next release

The next release, 0.97, is in development. Testing [release candidates](https://github.com/goatpig/BitcoinArmory/releases) when they are published and reporting what you find is one of the most useful contributions you can make.

Before starting on something larger, comment on the related issue so that no one else ends up working on the same thing.
