How offline signing works

Your private keys stay on a computer that never connects to the internet. A watching-only copy of the wallet does everything that needs a connection.

  1. Create

    On the online computer, the watching-only wallet shows your balance and prepares an unsigned transaction.

  2. Carry it over

    Save the unsigned transaction to a USB key and take it to the offline computer.

  3. Sign

    The offline computer, which holds the private keys, shows you the recipients and fee to confirm, then signs it.

  4. Broadcast

    Bring the signed transaction back. Armory sends it to the network through your own Bitcoin Core node.

What else Armory does

Watching-only wallets

Give an online computer a copy of the wallet without its keys, to see the balance and create new receiving addresses.

Paper backups

One paper backup, plus its SecurePrint code if you used one, restores every address the wallet generates. Imported keys need their own backup.

Your own node

Armory reads the blockchain from your Bitcoin Core node instead of a third-party server.

Open source since 2011

All the code is public on GitHub, and stable releases come with GPG-signed checksums.

Check every download

Armory releases since 0.94 are signed with goatpig's offline signing key. Compare this fingerprint, character by character, with the one GPG shows you:

745D 707F BA53 968B DF63 AA8D 8C52 1176 4922 589A

Short key IDs such as 4922589A can be forged. Always use the full fingerprint.

Maintained since 2011

Armory has been developed for {{ site.time | date: '%Y' | minus: 2011 }} years: by Alan Reiner and Armory Technologies until 2016, and since then as a community project led by goatpig.

  1. 2011

    Alan Reiner writes the first code of Armory.

  2. 2014

    Armory 0.92 adds multisignature lockboxes.

  3. 2016

    goatpig takes over and Armory continues as a community open-source project.

  4. 2017

    Armory 0.96.2 enables SegWit addresses on mainnet.

  5. 2018

    Armory 0.96.5, the current stable release, can send to bech32 addresses.

  6. Today

    Armory {{ site.data.project.next.version }} is in development, moving to Python 3 and a new wallet format. See the roadmap.
