Armory is now accepting Transifex translations to allow for future multi-language support. There will also be Transifex translations for the website coming soon.

Please help us translate on [Transifex](https://explore.transifex.com/bitcoin-armory/bitcoin-armory-software/).

*Update (2026): the Transifex project has moved to the address linked above. Armory's translation files were last synced from it in 2017, and website translations were never set up. See the [Contribute](/contribute/) page for the current status.*
